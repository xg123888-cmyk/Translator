# Translator

一个简洁、隐私优先的 Android 中英离线翻译器。

## v1.0 功能
- English → 中文 / 中文 → English
- 内置本地常用词与短语库
- 完全离线，不上传翻译文本
- 翻译历史
- 一键复制
- GitHub Actions 自动构建 APK

## APK
每次推送到 `main` 后，打开 **Actions → Build Android APK**，构建成功后在页面底部下载 `Translator-APK` artifact。

> 当前 v1.0 先以“稳定可编译”为目标。后续可以继续加入更大的离线词库、语音输入、朗读和真正的神经网络离线翻译模型。
